Mentions légales

Cette page dit qui diffuse Training Shop, et quelles données l'application manipule vraiment.

Éditeur

Training Shop est une application d'entraînement (projet training-front). Elle n'est pas éditée par une société et n'a pas d'adresse commerciale. La personne qui lance le projet sur sa machine en est l'éditeur le temps de la session.

Hébergement

L'interface est servie en local par le serveur de développement Angular, en général sur http://localhost:4200. Le catalogue, la connexion et la fiche de profil viennent de DummyJSON (dummyjson.com). Cette application n'héberge pas ces données.

Données collectées

Identifiants envoyés à DummyJSON

Le formulaire de connexion envoie le nom d'utilisateur et le mot de passe à https://dummyjson.com/auth/login. Ce sont des comptes de démonstration fournis par DummyJSON. Le mot de passe n'est pas enregistré : le formulaire est vidé après l'envoi.

Jeton d'accès

La réponse contient un accessToken. L'application le range dans le localStorage du navigateur, sous la clé token. L'intercepteur HTTP l'ajoute ensuite dans l'en-tête Authorization: Bearer, uniquement sur les requêtes envoyées à dummyjson.com. Le refreshToken renvoyé par DummyJSON n'est pas conservé.

Le jeton reste jusqu'à la suppression de cette clé, ou jusqu'à l'effacement des données du site. Une réponse 401 de l'API le retire aussi.

Panier

Les produits ajoutés (identifiant, titre, prix, image) restent dans la mémoire de l'onglet. Ils ne sont pas écrits dans le localStorage et ne sont pas envoyés à un serveur. Recharger la page vide le panier.

Cookie de DummyJSON

DummyJSON documente que la connexion dépose aussi les jetons accessToken et refreshToken dans des cookies du domaine dummyjson.com. Cette application ne demande pas au navigateur de renvoyer ces cookies : elle n'utilise que le jeton copié dans le localStorage. Comme le site local et dummyjson.com sont deux domaines distincts, le navigateur peut en plus refuser ces cookies.

Fiche de profil

Une fois la personne connectée, l'application interroge https://dummyjson.com/auth/me et affiche la fiche de démonstration (identité, contact, adresse, informations bancaires et techniques). Cette fiche n'est pas recopiée dans le localStorage.

Pourquoi ces données, et combien de temps

  • Identifiants : obtenir un jeton de démonstration, au moment où la personne se connecte.
  • Jeton : appeler l'API DummyJSON pour cette session, jusqu'à l'effacement du localStorage.
  • Panier : afficher les produits choisis, le temps de vie de l'onglet.
  • Cookie DummyJSON : posé par DummyJSON. Sa documentation indique une durée d'environ une heure par défaut pour le jeton d'accès. Cette application ne s'en sert pas.
  • Pas de mesure d'audience, pas de publicité, pas de revente.

Vos droits

Le RGPD reconnaît un droit d'accès, de rectification, d'effacement, de limitation, d'opposition et de portabilité.

  • Effacer le jeton local : supprimer la clé token dans les données du site, ou effacer les données de navigation pour cette origine.
  • Effacer le panier : bouton « Vider le panier », ou recharger la page.
  • Les fiches DummyJSON sont des données de démonstration hébergées par ce service. Cette application n'a pas de base d'utilisateurs à rectifier.

Il n'y a pas de délégué à la protection des données : le site n'est pas publié. Une réclamation peut être adressée à la CNIL (cnil.fr).
